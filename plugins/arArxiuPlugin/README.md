Arxiu AtoM Plugin
====================

This plugin provides a set of tools for managing AtoM instances, including:
- AtoM validation tools: duplicate detection, hierarchy validation, and more.
- AtoM maintenance tools: database backup, log management, and more.
- AtoM deployment tools: deployment scripts, configuration management, and more.

Features
===
- Duplicate detection: Identify and manage duplicate records in AtoM. It will also add tools to manage duplicates, such 
  as reassigning terms, merging records or deleting duplicates.
- Hierarchy validation: Ensure the integrity of hierarchical relationships in AtoM.
